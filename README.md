# Padosi – Local Services Marketplace

A single-page marketplace where users find local service providers, read reviews, and request bookings.
Built with HTML, CSS and JavaScript (no frameworks) for the NIAT Generative AI assessment.

## Features
1. **Provider profiles** – each provider has a profile with service, area, experience, price and bio.
2. **Search by service** – live text search plus category filters and sorting (rating, price, reviews).
3. **Reviews** – read existing reviews and post your own star rating and comment.
4. **Booking requests** – send a request with date, time and notes; track it under "My requests".

Also includes a **provider flow** (Become a provider form) alongside the **customer flow** (search → review → book).

## Run locally
Open `index.html` in a browser. No build step needed.

## Data
Sample providers are built in. Reviews, bookings and new providers are saved in the browser's localStorage.
